# Playing and controls

## Menus

Boot lands on a title screen. Single player leads to world selection and creation;
multiplayer reads a server address. A pause screen is available in a world.

## Options

Nine options screens cover video, controls, sound and the rest. Settings take
effect immediately and persist under Minecraft's own option key names, so they
read like the original's options file.

## Keys

There are 34 rebindable keys. The defaults follow the original's layout.

## Debug overlay

An F3-style overlay shows position, chunk, frame timing and the streaming
counters. F5 cycles the camera.

## In the world

You can break blocks, with crack stages and particles. A spawn menu creates
entities, and entities are drawn as box models. The sky follows a day cycle with
weather.

## Performance notes

World generation in the editor is slow, and the import and icon pipeline can still
cost a long frame. See [Known issues](/docs/minecraft/known-issues).
